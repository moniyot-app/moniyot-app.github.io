# רמוניות

אפליקציה לניהול סלי מוניות חודשיים למבצעים, סדרן והמנהלת.

- `src/app.html` – קוד המקור (גם לגרסאות הניסיון בתוך Claude).
- `tools/build.py` – בונה את `index.html` לאתר (מחובר ל-Supabase).
- `tools/schema.sql` – מבנה המאגר וההרשאות.

עדכון גרסה: עורכים את `src/app.html`, מריצים `python3 tools/build.py`, ומעלים.
